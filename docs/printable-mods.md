# Printable Mods

Printable parts made for the Creator 5 and 5 Pro from the community of the OpenCreator project.

## Leveling tool

[OpenCreator FlashForge Creator 5 Leveling Tool](https://www.printables.com/model/1888811-official-opencreator-flashforge-creator-5-leveling) on Printables.

A tool for leveling the bed. Use it with `C5_SCREWS_TILT`, which probes the
bed screws and tells you how far to turn each one. Made by @SycoAniliz.
