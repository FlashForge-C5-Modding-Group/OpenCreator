# Plugin repositories

These optional plugins are maintained in their own repositories. See
[Plugins](plugins.md) for installation and update commands.

## Orca Filament Profiles

Choose the OrcaSlicer preset that filament sync selects for each material AFC
reports. For example, map `PLA` to **Flashforge PLA Color Change** so it is
selected when you sync the printer's filament list.

The plugin requires OrcaSlicer 2.5 or later and an OpenCreator AFC build that
publishes lane data to Moonraker. AFC's own filament IDs take precedence when
available. The repository README explains how to install the plugin and set
your mappings. [Orca Filament Profiles repository](https://github.com/Xmister/opencreator-orca-filament-profiles)
