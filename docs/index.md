# OpenCreator

OpenCreator is the documentation site for the Creator 5 full-custom-firmware
project. This is an initial documentation scaffold; printer-facing procedures
will be added as they are verified.

Start with [Getting started](getting-started.md) to find the project sources,
or see [Project layout](project-layout.md) for the repositories that make up
the work.

!!! warning "Hardware procedures are not published yet"
    Do not treat this site as a flashing or recovery guide until those pages
    include tested steps, supported versions, and rollback instructions.
